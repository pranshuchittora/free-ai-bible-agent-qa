# Pick an image-generation workflow

| Need | Start with | Tradeoff |
|---|---|---|
| Build visual workflows | ComfyUI | Setup, model downloads and hardware requirements |
| Try downloadable weights | FLUX.1 schnell | Check memory needs; its Apache-2.0 license differs from other FLUX variants |
| Learn a simple REST wrapper | [Stable Diffusion API starter](../templates/image-gen-api/) | First download; CPU inference can be slow |
| Browser-only generation | Check image services marked “needs review” | Confirm the current allowance, watermark, privacy and commercial terms first |

[Search the image category](https://abbosaliboev.github.io/free-ai-bible/catalog.html?category=image&reviewed=1). Avoid assuming all model variants share a license or that free outputs are commercially cleared. Evaluate prompts and output quality for your own task.
