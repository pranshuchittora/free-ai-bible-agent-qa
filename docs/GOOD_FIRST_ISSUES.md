# Small tasks with a clear finish line

Pick one task, check existing issues/PRs to avoid duplicate work, then open an issue or PR. These are suggested tasks, not claims that issues have already been opened.

| Task | Done when | Suggested label |
|---|---|---|
| Recheck one earlier cloud entry | Official pricing linked, access/card/limits recorded, data regenerated | `good first issue`, `verification` |
| Review Arabic wording | A fluent speaker checks the guide, links and RTL rendering; PR explains changes | `good first issue`, `translation` |
| Test chatbot on Windows | Python version, commands and result documented; fixes reproduce | `help wanted`, `template` |
| Test local RAG on Linux | Both models downloaded, sample question works, environment reported | `help wanted`, `template` |
| Evaluate Arabic speech | Qwen3-ASR or Whisper tested on consented audio; dialect and qualitative findings reported without uploading private recordings | `help wanted`, `arabic` |
| Improve a no-results message | Describe the user problem and show the result at narrow screen widths | `good first issue`, `accessibility` |
| Recheck one image/video plan | Distinguish free tier, trial and credits; remove unsupported daily quotas | `good first issue`, `verification` |
| Add a language you maintain | Short guide, working links, shared catalog reference and reviewer identified | `help wanted`, `translation` |

No coding is required to verify a resource or improve a translation. [Contribution steps](../CONTRIBUTING.md).
