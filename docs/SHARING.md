## English

**Your next AI side project might need fewer subscriptions.**

I maintain Free AI Bible: a searchable collection of free-tier APIs, local models, coding assistants and starter projects. It shows the limits, card requirements when known, official sources and review dates — including entries that still need checking.

New additions include Qwen3, local coding tools, document processing and speech models. There is an Arabic guide too.

Try the directory: https://abbosaliboev.github.io/free-ai-bible/catalog.html

Code + starters: https://github.com/abbosaliboev/free-ai-bible

⭐ Save it for your next build. Found a changed limit or a missing tool? One correction is a useful contribution.

## العربية

أطوّر Free AI Bible: دليلًا قابلًا للبحث لواجهات AI ذات الحصص المجانية، والنماذج المحلية، وأدوات البرمجة، وأمثلة جاهزة للبدء. يعرض القيود والمصادر الرسمية وتواريخ المراجعة، ويُميّز المعلومات التي ما زالت تحتاج إلى التحقق.

أضفنا دليلًا بالعربية ونماذج وأدوات للصوت والمستندات والبرمجة.

الدليل: https://abbosaliboev.github.io/free-ai-bible/catalog.html

المستودع: https://github.com/abbosaliboev/free-ai-bible
