## Limitaciones importantes

Un plan gratuito no implica capacidad ilimitada. Las herramientas locales requieren hardware y electricidad; algunas integraciones usan APIs de pago. “Docs reviewed” significa que se consultó una fuente oficial, no que se probó una cuenta ni su rendimiento. Las cuotas y fechas están en el catálogo compartido.
