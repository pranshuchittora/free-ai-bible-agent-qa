## 重要な制限事項

無料プランは無制限とは限りません。ローカルツールにも機器と電力が必要で、一部の連携には有料APIが使われます。“Docs reviewed”は公式ページの確認を意味し、アカウントや性能のテストではありません。利用枠と確認日は共通カタログをご覧ください。
