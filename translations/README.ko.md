## 알아둘 제한 사항

무료 요금제가 무제한 사용을 뜻하지는 않습니다. 로컬 도구에도 하드웨어와 전력이 필요하며 일부 연동은 유료 API를 사용합니다. “Docs reviewed”는 공식 문서를 확인했다는 뜻이며 계정이나 성능 테스트를 의미하지 않습니다. 사용 한도와 확인 날짜는 공통 카탈로그를 참고하세요.
